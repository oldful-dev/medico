---------- DEPLOYMENT WORKFLOW ----------
1. Push code to main branch
   git push origin main

2. GitHub sends webhook to:
   https://api.ayuxacare.com/deploy

3. Webhook receiver verifies signature
   (using GITHUB_WEBHOOK_SECRET)

4. Checks if backend/ files changed

5. Runs /opt/scripts/deploy.sh which:
   - Pulls latest code
   - Installs dependencies
   - Runs migrations
   - Restarts PM2 app

6. Verify with:
   pm2 logs medico-api
